# Security policy

Please report security problems **privately**. Do not open a public issue.

- Preferred: open the repository's **Security** tab on GitHub and choose **Report a vulnerability**.
- Or email **hello@everybodyai.dev** with "SECURITY" in the subject.

Say what you found, how to reproduce it, and which version or commit you used. You will get a reply as soon as
possible, normally within a few days. The fix and the advisory will credit you unless you would rather not be named.

Security fixes go into each project's latest release. A repository with a `SECURITY.md` of its own (such as
[QuickAI's](https://github.com/everybodyai/quickai/blob/main/SECURITY.md)) says what that project promises, and so
what counts as a vulnerability there.
