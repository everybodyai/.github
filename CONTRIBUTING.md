# Contributing to EverybodyAI's projects

Thank you for helping. Bug reports, ideas, documentation and code are all welcome.

This is the default guide for every repository of EverybodyAI. A repository with a `CONTRIBUTING.md` of its own
(such as [QuickAI's](https://github.com/everybodyai/quickai/blob/main/CONTRIBUTING.md)) has the details for that
project: how to build it, the checks to run, and how its code is organized.

## Before you start

- **Found a bug or have an idea?** Open an issue in the repository it belongs to.
- **Have a question?** Ask in [QuickAI's Discussions](https://github.com/everybodyai/quickai/discussions).
- **Found a security problem?** Report it privately, as [SECURITY.md](SECURITY.md) describes. Do not open an issue.
- **Planning a larger change?** Open an issue first, so that we can agree on the approach before you put in the work.

## Privacy is a feature

Our tools make promises about what they do not do. A change that makes one contact the network, or store something
new, must be something the person asked for, must say what it contacts, and must update that project's privacy
policy in the same pull request.

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
